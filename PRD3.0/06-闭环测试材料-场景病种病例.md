# 闭环测试材料：新增场景 → 新增病种 → 新增病例

> **目的：** 从管理端三选一走通一条可演示闭环，并**听得出来**对话贴合新病种/病例。  
> **账号：** `admin` / `Admin2026`  
> **地址：** http://127.0.0.1:8000/（先 `Ctrl+F5`）  
> **样例文稿（三路径内容不同，勿混用）：**  
> - 写大概：[`web/data/samples/sample-rough-zhouayi-family-copd.txt`](../web/data/samples/sample-rough-zhouayi-family-copd.txt)  
> - **交材料 ZIP：**[`web/data/samples/sample-material-zhouayi-family-copd-with-junk.zip`](../web/data/samples/sample-material-zhouayi-family-copd-with-junk.zip)  
> - 纯人写：[`web/data/samples/sample-human-zhouayi-family-copd.txt`](../web/data/samples/sample-human-zhouayi-family-copd.txt)  
>
> ZIP = 碎片笔记+垃圾文件；纯人写 = 结构化全文。场景选家属协同（正式）· 病种 COPD。

## 先说清楚：对话靠什么「贴」新场景/病种/病例？

| 你新建的 | 对话里现在怎么体现 | 还缺什么 |
|----------|--------------------|----------|
| **病例事实**（周阿姨漏吸、买止咳药…） | SP Prompt 注入锁死事实、开场、担心点 → **立刻能听出来** | — |
| **病种**（COPD） | Prompt 有【病种锚定】；开练页显示病种 + 侧重点 | 无专用 overlay 时**评分**仍偏通用随访表 |
| **场景（知情/随访）** | 有专用扮演规则（含糊→追问才说实话 / 知情反复问退出） | — |
| **新场景条目**（本套用「家属协同沟通」） | 可登记；**本期病例发布仍只能挂知情/随访白名单** | 要可练须：评分包 production + 白名单放开 + 场景规则（见下） |

**结论：** 本闭环要验证的是「**新病种 + 新病例**在**随访**局下对话是否贴 COPD」；「新场景」做登记演示，不拿去发布可练（系统里已有「风险解释」等预留，勿重复）。

### ② 新增病种

| 字段 | 填什么 |
|------|--------|
| 病种名称 | `慢性阻塞性肺疾病` |
| 编码 | 可留空（AI 自动生成），或手填 `COPD` |
| ICD | `J44`（可选） |
| 短说明 | `吸入剂试验随访用 · 闭环测试病种`（可选） |
| **病种介绍**（必填） | 见下方「介绍文案」 |

**病种介绍文案（复制）：**

```
慢阻肺（COPD）以持续气流受限为特征，常见气短、慢性咳嗽咳痰。吸入剂试验随访时，受试者可能漏吸、自行买止咳/感冒药，怕被说不配合或踢出试验。沟通应贴合呼吸与吸入器使用体验，平和追问漏吸原因与合并用药，勿串成高血压量血压或糖尿病测血糖话术。
```

## 对话怎么验收（充分贴合？）

开练周阿姨后，至少听/看到：

| # | 验收点 | 过 |
|---|--------|----|
| 1 | 开练 briefing：**病种**显示 COPD；有「本局侧重点」更好 | ☐ |
| 2 | 开场口语像带孙子、催时间、提「吸药/咳」，**不像**高血压量血压话术 | ☐ |
| 3 | 问漏服：先含糊「基本上天天吸」，平和追问后才说漏吸/顾孙子 | ☐ |
| 4 | 问合并用药：能说到自己买止咳/感冒药（材料里有） | ☐ |
| 5 | 结束报告：清单是**随访**大类；若无 COPD overlay，侧重点可能仍是通用随访（正常） | ☐ |

若开场仍像「高血压第 4 周」，说明病例材料没进包或选错人——回已发布核对病种/主诉。

## 逐步操作

### Step 0
登录 `admin` / `Admin2026` → `Ctrl+F5` → **病例与场景** → 确认按钮顺序：场景 · **病种** · 病例

### Step 1 · 新增场景
填「家属协同沟通（测试）」→ 保存 → 返回新建  
☐ 未与「风险解释」撞名　☐ 无材料三路径

### Step 2 · 新增病种
填 COPD → 保存 → 返回新建  
☐ 列表有 COPD　☐ 病种在病例入口前

### Step 3 · 新增病例并发布
随访 + COPD + 粘贴周阿姨 → 扩写/整理 → 人审 → 发布  
☐ 审核页有评分包摘要　☐ 已发布可见

### Step 4 · 学员端对话验收
学员登录 → 选周阿姨 → 开练 → 对照上表「听什么」  
☐ 病种可见　☐ 口吻贴 COPD　☐ 含糊→追问才松口

## 常见卡住

| 现象 | 怎么办 |
|------|--------|
| 想挂「家属协同」发布失败 | 本期只能挂知情/随访；新场景仅登记 |
| 与风险解释搞混 | 本套用 `family_proxy_talk_test`，不要再建 risk_explanation |
| 对话不像 COPD | 确认选的是周阿姨；重启服务使 Prompt 注入生效；看 briefing 病种行 |
| 扩写失败 | 改用「内容你已写全」+ [`sample-human-zhouayi-family-copd.txt`](../web/data/samples/sample-human-zhouayi-family-copd.txt) |
| 要测交材料 | 用 ZIP：[`sample-material-zhouayi-family-copd-with-junk.zip`](../web/data/samples/sample-material-zhouayi-family-copd-with-junk.zip)，勿与纯人写全文当成同一份 |
