## 实现落点（代码）

- 前端：`web/js/admin.js`（新建 hub + 三页；审核页展示评分包）
- 场景 API：已有 `POST/DELETE /api/admin/scenes`
- 病例接入：仍走 ingest 草稿 → 人审 → 发布（无评分包不可发布）
- 评分注册表：`web/data/scoring/registry.json`
- 病种叠加：`web/data/scoring/overlays/*.json`
- 引擎：`case_loader.load_effective_rubric` / `load_rubric_for_case` → `sessions` / `scoring_engine`
- 自测：`python scripts/test_scoring_effective.py` · `python scripts/test_scoring_phase1.py`
