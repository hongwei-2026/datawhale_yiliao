## 三个核心概念（一句话版）

1. **清单为主：** 按规范小项反馈达标/未达标；参考分是教学汇总（须说明），不靠问卷赋分。  
2. **双层结构：** 底下 GCP 小项算分（A），上面大类给人看（B）— 不推翻旧引擎。  
3. **两种模式：** 练习细、考核粗；结束都有报告；聊太少 = 无参考分。

## 优先级（组会后定稿）

| 级别 | 做什么 | 不做什么（演示可忽略） |
|------|--------|------------------------|
| **P0** | Word→JSON（groups）、开练大类导览、练习过程 coverage、考核粗进度、insufficient 文案 | — |
| **P1** | prompt_examples、answer_pool 文档化、HTN+T2DM 各练 10 次验 A 层 | 全屏考核 UI |
| **P2** | Live2D / 语音 / MuseTalk | 答辩不必展开 |
| **P3** | 管理端「写大概/交材料/纯人写→人审」；**仅知情+随访**（见 [11](./11-管理端病例接入.md)） | 主推 JSON 包；无审核上架；把预留场景码当可用 |

---

## 答辩 5 分钟脚本

1. 选受试者 → 2. 看 **五个大类 + 红线** → 3. 练习模式聊 4～6 轮（指进度）→ 4. 结束看 **大类报告** → 5. 一句考核规则 + 一句「短练无参考分防刷分」

**数字人、语音各 ≤30 秒。**
