# 调研笔记：会追问 / 可控的医疗对话 AI

> 目的：支撑「问题引擎 + 评分表驱动对话」。  
> **组会补充：** 业界拆法不变，但 **我们先定评分大类小项**，再改引擎和 SP。

---

## 1. 共性结论

```text
学员一句 → 意图/阶段 → 病例事实门控 → SP 回复（长度看人设+情绪）→ 过程覆盖 → 结束分项评
```

**成败关键：** 评分标准清楚 + 对话可控，不是皮肤多真。

---

## 2. 代表方案（摘要）

| 方案 | 启发 |
|------|------|
| SAPS | 动作分类 + 病历片段 + 生成 |
| EasyMED | 意图 / 病人 / 评价 解耦 |
| Agent Hospital | 未问不泄、主诉优先 |

映射到 AISP：见下表。

---

## 3. 映射到 AISP（组会后）

| 业界 | AISP |
|------|------|
| State Tracker | 意图 → **评分小项** 覆盖 |
| Memory Bank | case JSON + **answer_pool** |
| Patient Generator | `patient_agent` + **人设控长度**（非全员短句） |
| Evaluation | `scoring_engine`（A 层）+ **groups 展示**（B 层） |
| 导览 | 开练前 **大类 + 红线**（09 文档） |

---

## 4. 不建议照搬

- 全套多 Agent 编排（慢、贵）→ MVP 用 **规则 + 单次 LLM**  
- 语音情绪当核心 → 先 **文本 + 进度条**  
- 追求真人 SP 100% → 目标是 **清单覆盖 + 红线不踩**

---

## 5. 实现顺序（与 09、04 对齐）

1. **蔡文香 Word 评分表** → JSON `groups` + `group_id`  
2. 开练导览 + **练习模式过程覆盖**（规则）  
3. `answer_pool` + 多样性可见性（齐立原 demo）  
4. 结束报告（练习/考核都有）；样本不足 → 温和提示，非 2 轮刷分  
5. （可选）LLM 语义评小项；HTN+T2DM 各练 10 次验 A 层
