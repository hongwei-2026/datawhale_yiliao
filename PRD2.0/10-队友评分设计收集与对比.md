# 队友评分设计：认可吸收与对照

> **用途：** 标明队友材料里 **我们认什么、不认什么**，以及如何并入 [09-评分体系与练习考核.md](./09-评分体系与练习考核.md)。  
> **原件：** [`队友对评分设计的收集与设计/`](./队友对评分设计的收集与设计/)

---

## 一、结论（组内已定）

| 态度 | 内容 |
|------|------|
| **认可并吸收** | ① 法规/综述证明「知情 + 随访必须作为训练要点」② 条目清单思路与红线类型 ③ 五类 SP 应答差异 ④ 李建国高血压随访病例专项表（映射现有 FU） ⑤ 人文关怀应在反馈里可见 |
| **不认可** | ① 问卷 n=18 作赋分/答辩数据 ② A48+B24+C16+D12 及条目整数分当作权威权重 ③ 关键词覆盖 ≥80% = 完全正确 |
| **我们自己的方案** | **清单核对为主**（达标/未达标）+ **可选参考分**（教学汇总，须说明）+ 语义判定；真源见 `scoring-rubric*.json` |

对外一句：  
**队友帮我们补「评什么」和病例/人设材料；「评多少分」不靠她的问卷表，我们用清单 + 教学参考分。**

## 二、认可部分 → 怎么用进产品

### 2.1 法规「评什么」（`评分标准参考来源`）

- **用：** 知情同意、随访为何是两大场景；条款索引可与 `standards-registry.json`、rubric `sources` 交叉核对。  
- **不用：** 文中旧「A50/B50」或任何整数赋分暗示。

### 2.2 条目与红线（简明表 / 五类模板里的评分点）

- **用：** 对照检查我们 IC/FU 小项是否漏了「退出、风险、隐私、补偿、漏服、合并用药、药盒日记、非责备」等；红线类型（编造、诱导、含糊、瞒风险 / 责备、自行医嘱）与 `IC-X*`、`FU-X*` 对齐完善。  
- **不用：** 她表上的具体分值（15、12…）和 A/B/C/D 切分当作引擎权重。

### 2.3 五类 SP（低认知 / 普通 / 高知 / 焦虑 / 随和）

- **用：** 丰富 [01-场景设计.md](./01-场景设计.md) 人设与应答差异；李建国 = 普通型（配合-回避）兼焦虑/低认知成分，与现病例一致。  
- **落地：** Phase 2 做人设字段对齐，不必一次做满五种病例 JSON。

### 2.4 李建国病例应用表

- **用：** 隐藏事实、追问路径、普通型话术 → 与 `scoring-rubric-followup.json`（FU-A01…）**映射试跑**，验证 demo。  
- **不用：** 整表替换引擎；不引入关键词 80% 判定。

### 2.5 人文关怀

- **用：** 保证 B 层展示 / 报告里「人文·沟通」可见（知情 G-01、随访 G-01）；随访强调非责备。  
- **不用：** 单独再做一个「C 维 16 分」法定结构。

---

## 三、不认可部分（答辩勿用）

1. **问卷 n=18：** 样本小、偏差大，她自己也承认 → **无参考价值**。  
2. **A48… 整数权重：** 规范与 SEGUE/QuIC **都不规定**这种切分；是设计约定 + 问卷叙述，不能当我们的权重真源。  
3. **关键词 ≥80%：** 改为与 09 一致的 **语义 pass / uncertain / fail**；词表最多当 `prompt_examples`。

## 四、材料清单（备查）

| 文件 | 我们怎么用 |
|------|------------|
| 调研问卷 / 分析结果 | 过程记录；**数字不用** |
| 修订前后对比及赋分依据 | 看她叙事；**分值不采纳** |
| 训练评分标准简明表 | 条目/红线对照用 |
| 五类 SP 应答模板 | **吸收**人设差异 |
| 李建国病例应用 | **吸收**随访考点与对话；映射 FU |
| 评分标准参考来源 | **吸收**「评什么」与场景理由 |
