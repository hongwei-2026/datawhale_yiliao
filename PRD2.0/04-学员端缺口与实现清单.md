> **组会后重点：** 不是再加 Tab，是把 **对话 + 双层评分进度 + 结束反馈** 做清楚。  
> 设计真源：[09-评分体系与练习考核.md](./09-评分体系与练习考核.md) · 正式答复：[08-小组讨论纪要](./08-小组讨论纪要-2026-09-02.md)

## 1. 学员应该经历的一条线（像看电影）

```text
登录 → 选张大爷/李建国
    → 开练前看「五个大类 + 红线」（今日任务单）
    → 练习模式：聊几轮，侧栏进度跟着变
    → 点结束：大类折叠报告 + 小项明细 + 建议
    → （可选）考核模式：过程只有粗条，考完同样看报告
```

**无语音、无数字人** 也必须能完整走通 — 答辩默认这条路径。

## 5. 练习 vs 考核 · 界面差异（开发对照表）

| | 练习 `practice` | 考核 `assessment` |
|---|-------------------|-------------------|
| 侧栏进度 | ✅ 大类 + 小项「可能已覆盖」 | ✅ **仅** 大类 % |
| 过程「已得 X 分」 | ❌ 不显示 | ❌ 不显示 |
| 心情 HUD | ✅ | ❌ |
| 病例参考 | 可开 | 关 |
| 提前结束 | ✅；够样本则正式分 | 可交卷 |
| 样本不足 | 温和提示，无参考分 | 同左 |
| **结束后** | 总分 + 大类 + 小项 + 建议 | **同样必须有**（标题「考核报告」） |

## 8. 验收（对齐 09 §16）

- [ ] 开练前见 **大类 + 红线 + 问法示例**  
- [ ] 练习 4～6 轮，**小项/大类进度**有变化  
- [ ] 聊不足 3 轮 → **温和提示**，非报错  
- [ ] 聊够轮次 → **大类折叠 + 小项** 结束报告  
- [ ] 考核：过程 **仅粗进度**，结束 **有报告**  
- [ ] 同病例 3 次，开场/措辞不同、事实一致  
- [ ] 演示 **不依赖** 语音 / 数字人
