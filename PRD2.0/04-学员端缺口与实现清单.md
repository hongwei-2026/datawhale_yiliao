## 1. 已确认缺陷（代码侧）

| 问题 | 根因（分析） | 修复策略 |
|------|----------------|----------|
| 退出再进只剩一条/空 | 前端 `state.practice` 不持久；`openPracticePicker` 清空 messages；未自动 resume | `localStorage` 存 `sessionId`，进练习页自动 `resumePractice` |
| 对话框像「只有一句」 | `.gal-dialog-glass` 高度仅 `min(38vh,340px)`，历史需上滑，易被忽略 | 提高默认高度 +「展开全部对话」+ 恢复后滚到底并提示条数 |
| 反馈页无完整对话 | `loadFeedbackDetail` 只拉 feedback，不拉 messages | 反馈/记录增加 transcript |
| 历史「没了」 | 换云库 / 换账号会空；或未点「对话记录」加载 | 记录页强化空态说明；同账号同库可查；进行中摘要可见 |
| 无开练导览 | 无沟通点前置 | 选人后、开练前展示阶段 checklist |
| 无过程进度 | 无 stages UI | 启发式阶段条（先前端，后接引擎） |
| 未完成无摘要 | resume 卡只有消息数 | 增加「第 x/8 步 · 最后一句摘要」 |

## 2. 产品能力定义

### 2.1 开练前导览

- 展示本场景 8 个沟通阶段（知情）或随访要点  
- 一句话说明：练完对照这些点看反馈  
- CTA：开始练习 / 继续未完成  

### 2.2 过程态

- 对话区上方：阶段进度（todo / active / done）  
- 不阻断发送；仅提示覆盖情况  

### 2.3 未完成摘要

- 列表：受试者、开始时间、消息数、当前阶段、最后一条病人/学员摘录  
- 点击 → 完整恢复对话 + 阶段  

### 2.4 历史与复盘

- 对话记录：练习/考核筛选不变  
- 已结束：可「查看对话」全文 +「查看反馈」  
- 反馈页：分项下增加「本次对话全文」  

### 2.5 Live2D

- 默认呈现改为 Live2D（见 05）；MuseTalk 关闭  

### 2.6 系统功能 Tab

- **本迭代不做**（后置）
