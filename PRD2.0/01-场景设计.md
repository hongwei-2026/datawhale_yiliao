# 场景设计（PRD 2.0）

> 本文回答：**场景是什么**、**同一场景为何有多人**、**开练前学员要掌握什么**、**人设×场景×情绪如何共同驱动 SP 行为**（不只话多话少）。  
> 评分见 [09-评分体系与练习考核.md](./09-评分体系与练习考核.md)；引擎见 [02-问题引擎与对话多样性.md](./02-问题引擎与对话多样性.md)。

## 一、先从一个学员的四次练习说起

小刘是 CRC，要用 AISP 练沟通。

**第一次 · 张大爷（知情同意）**  
开练前，页面除了告诉他「今天练五块：人文、试验内容、关切、流程、红线」，还应有一张 **病人背景卡**：68 岁退休男，T2DM 8 年，口语偏慢，**会反复问退出和疗效**。  
聊起来，大爷果然一再问：「我能中途不参加吗？」「这药一定有效吗？」——小刘练的是 **讲解 + 回应关切**，不是连珠炮审问。

**第二次 · 王阿姨（同一场景、同一张评分表）**  
背景卡换了：72 岁，听力略差，女儿常陪同，**脚麻、视物模糊**，阅读 ICF 慢。开场：「您说慢点，我耳朵不太好。」  
大类没变，但小刘必须 **放慢、确认听懂**，并回应脚麻/视力——**同考纲，不同人，策略要换**。

**第三次 · 张大妈（知情，设计稿）**  
背景卡：65 岁独居，**先问钱、跑几趟、邻居说试验不靠谱**。她焦虑时 **话多**；你若敷衍催签，她 **突然变短、想走**。

**第四次 · 李建国（随访，另一场景）**  
背景卡：56 岁出租车司机，HTN III 期 **第 4 周随访**，桌上有 **药盒、日记、血压本**；嘴上「基本都吃了」，病例里锁着 **3 次漏服、头晕、加药、日记补记**。  
局变了：**你在问，他在答**——笼统问「都吃了吧」不够；责备一句，他 **更短、更瞒**。

**四趟下来，场景设计要交付两件事：**

1. 开练前知道 **练什么**（评分大类 + 红线）  
2. 开练前知道 **这人是谁、今天什么局、你可能听到什么**（病人背景，不是对话里才猜）  

下面先搭 **架构**，再落四人、开练导览，最后用四人引出 **运行时三因素**（驱动的是整套 SP 行为，不只长短）。

## 三、场景设计 · 整体架构（先搭架子）

故事讲人，但产品要有 **可复用的架子**。我们把场景设计拆成 **三层**：

```text
┌─────────────────────────────────────────────────────────────┐
│ ① 场景层 Scene                                              │
│    这一「局」是什么：知情同意 / 随访                         │
│    配什么评分表、学员主责、桌上有什么、对话谁问谁答           │
├─────────────────────────────────────────────────────────────┤
│ ② 病例层 Case                                               │
│    同一场景下的具体人：张大爷 / 王阿姨 / 张大妈 / 李建国     │
│    试验方案可共用；人设、病况、开场、关切、藏话规则各自不同   │
├─────────────────────────────────────────────────────────────┤
│ ③ 运行时层 Runtime（每一轮对话）                             │
│    人设（整场稳定）× 场景角色（这一局）× 情绪（这一轮）       │
│    → 共同决定 SP「说什么、说到多深、怎么接话、语气、长短」  │
└─────────────────────────────────────────────────────────────┘
```

架构图：

<img src="assets/prd2-scene-architecture.png" alt="场景设计三层架构" width="100%" />

### 3.1 三层各自解决什么问题

| 层 | 回答的问题 | 没有这一层会怎样 |
|----|------------|------------------|
| **场景** | 今天是哪种临床沟通？考什么？ | 知情和随访混成一套话术，评分也对不上 |
| **病例** | 今天面对谁？背景是什么？ | 只会背「张大爷专用稿」，换人就穿帮 |
| **运行时** | 这一轮该不该松口、该不该重复、该不该变短？ | SP 要么复读机，要么 LLM 乱编 |

### 3.2 数据怎么落到文件（架构 → 真源）

| 架构层 | 主要落在哪 | 举例 |
|--------|------------|------|
| 场景 | `scene_key` + `scoring-rubric*.json` + `scene_bindings` | `informed_consent` / `follow_up` |
| 病例 | `web/data/cases/*.json` | persona、clinical_summary、adherence_facts、opening、hints |
| 运行时 | `patient_engine.py` + 每轮 session `emotion` | trust、stance、disclosure_depth、speak_style |

### 3.3 开练前界面怎么对应架构

| 学员看到的 | 对应哪一层 |
|------------|------------|
| 左卡「今日练什么」 | **场景** + 评分表大类 |
| 右卡「这人是谁」 | **病例** 背景与性格 |
| 对话中心情、松口/瞒话、接话方式、长短 | **运行时** 三因素 |

### 3.4 具体怎么设计（从架构到一次练习）

```text
1. 定场景层
   选知情 or 随访 → 挂评分表 → 写清学员主责、桌上物品、谁问谁答

2. 定病例层（同一场景可挂多人）
   写 persona / 病况 / 开场池 / 关切 / dialogue_hints / 锁死事实
   → 生成开练「右卡」

3. 开练
   左卡读评分大类；右卡读病例背景

4. 每一轮（运行时）
   读人设底色 → 套场景角色 → 按学员语气更新情绪
   → 决定本轮：说什么、说到多深、怎么接、语气、长短
   → 返回回复 +（练习）心情与进度
```

## 四、同一场景、多个病人 · 病例层怎么拆

**不变：** 试验方案、场景类型、评分表。  
**变：** 每个病人的 **背景、性格、开场、关切、藏话方式** —— 写在各自 `cases/*.json`。

同一张知情评分表，换一个人 = 换 **背景卡 + 沟通重点**，不是换考纲。

## 五、张大妈 · 病例怎么写（设计稿）

65 岁独居，**不信新药、怕花钱怕折腾**。开场池示例：

- 「邻居说试验不能乱参加，是不是拿我们试药？」  
- 「要先问清楚，要钱不要？跑几趟？」  

关切与评分大类：钱/补偿 → G-04；邻居式安全顾虑 → G-02+G-03；反悔 → G-03。  
`dialogue_hints`：说太快 → 请重复；dismiss 邻居 → 想走；讲清补偿 → G-04 可能覆盖。

与张大爷/王阿姨 **共用** 试验方案与同一张 IC 评分表；**单独写** persona、clinical_summary、opening_pool、dialogue_hints。

## 六、李建国 · 随访怎么练（已入库）

> 文件：`CASE-HTN-PH3-W4-001.json` · 故事细节：[03-病人AI思考逻辑.md](./03-病人AI思考逻辑.md)

### 6.1 与知情三人的本质不同（场景层差异）

| | 知情（张/王/张大妈） | 李建国 |
|---|---------------------|--------|
| 角色 | 你 **讲**，SP **问** | 你 **问**，SP **答** |
| 桌上 | 知情同意书 | 药盒、日记、血压本 |
| 评分大类 | 人文/试验/关切/流程 | **人文 / 用药核查(35) / 随访安排 / 红线** |

### 6.2 病例锁死的核查点（SP 不能乱编）

| 核查点 | 真相 |
|--------|------|
| 完全漏服 | 第 10、19、24 天，共 3 次 |
| 头晕 | 第 18 天，约 20 分钟，**未联系中心**；第 19 天自行停药 |
| 合并用药 | 第 21–22 天感冒药；第 26 天 **自行加氨氯地平** |
| 药盒 | 应剩 7 片，实剩 10 片 |
| 日记 | 第 10 天空白；第 19、24 天 **来前补记** |
| 血压记录 | 28 天应记满，只记 21 天；测法不规范 |

### 6.3 四幕 · 你怎么问，他怎么变（运行时）

1. 进门：「基本都吃了。」→ 太笼统，**不算问清漏服**（披露深度不够）  
2. 「都吃了吧？」→ 仍含糊 → **要具体日期**  
3. 「你怎么能忘！」→ **更瞒、抵触**（不只是变短）  
4. 「不是责怪，哪一天没吃？」→ **松口**：「去女儿家那天忘了……」→ 再追问才带出 10、19 天与药盒日记  

`dialogue_hints` 已入库：`if_blame`、`if_reassure`、`if_day_by_day`、`nudge_if_missed`。

### 6.4 学员忌

一轮混问漏服+头晕+药盒；责备；「你就加/停一片」——后两者是 **红线**。

## 八、从四个人引出：运行时三因素 · 驱动整套 SP 行为

前面已有场景层、病例层、开练左右卡。这里讲 **架构第③层**。

**容易写错：**「人设 + 场景 + 情绪 = 话多话少。」  
**不对。** 长短只是表现之一。三因素共同决定的是 **一整套 SP 行为**——学员练的也是对这套行为做反应。

### 8.1 公式（答辩用）

```text
人设（整场稳定） × 场景角色（这一局） × 情绪（这一轮）
        ↓
SP 这一轮至少五件事：

  ① 说什么 / 问什么     → 话题与关切点
  ② 说到多深           → 含糊还是具体、藏还是松口
  ③ 怎么接学员的话     → 重复确认、反问、敷衍、带出新线索
  ④ 语气与配合度       → 客气、紧张、抵触、想走
  ⑤ 说多长             → 只是第⑤项，不是全部
```

### 8.2 五件事 · 四人对照（不要只比长短）

| 行为维度 | 张大爷 | 王阿姨 | 张大妈 | 李建国 |
|----------|--------|--------|--------|--------|
| **① 说/问什么** | 反复问退出、疗效 | 脚麻、视力、平时看病 | 钱、跑几趟、邻居谣言 | 先「没事」；被问才谈漏服/头晕 |
| **② 说到多深** | 关切问两遍才安心 | 听清后才往下走 | 不信时只抱怨，信了才听流程 | **先含糊，具体问才披露真相** |
| **③ 怎么接话** | 听完再确认一遍 | 「说慢点」「再说一遍」 | dismiss→想走；讲清钱→愿意听 | 笼统→敷衍；责备→更瞒；安抚→「那我说实话」 |
| **④ 语气配合** | 谨慎、要听清 | 慢、怕听漏 | 半信半疑、怕折腾 | 客气但怕批评 |
| **⑤ 说多长** | 中等，爱重复 | 可因「请重复」变长 | 焦虑时长；敷衍时短 | 默认短；松口后可略长 |

→ 换人时，学员要换的是 **整套沟通策略**，不是「对这个人说短一点」。

### 8.3 人设 · 整场稳定的「底色」

人设回答：**长期关心什么、怕什么、理解方式怎样。**

| 人 | 稳定底色 | 主要影响 |
|----|----------|----------|
| 张大爷 | 谨慎、要听清退出和疗效 | ① 关切话题、③ 爱重复确认 |
| 王阿姨 | 听力差、阅读慢、怕拖累女儿 | ① 症状关切、③ 要慢讲确认 |
| 张大妈 | 不信试验、怕花钱怕折腾 | ① 钱与安全、④ 半信半疑、⑤ 长短随之变 |
| 李建国 | 怕做错、怕不能继续参加 | ② **藏话倾向**、④ 客气但防备 |

写在 `persona`、`lay_bio`、`key_concerns` —— 开练右卡事先给学员。

与队友「五类 SP」对照（**只吸收应答差异，不接 A48 赋分**；详见 [10](./10-队友评分设计收集与对比.md)）：

| 队友类型 | 我们现有人设大致对应 | 可借的应答差异 |
|----------|----------------------|----------------|
| 低认知 | 王阿姨（理解慢） | 要慢讲、重复确认 |
| 普通型 | 李建国（配合但可回避） | 表面配合、关键点藏 |
| 高知 | （可后补病例） | 追问细节、质疑表述 |
| 焦虑 | 张大妈 / 建国焦虑面 | 话多或防备、怕折腾 |
| 随和 | 张大爷偏配合面 | 愿听，但仍要听清权益 |

Phase 2 再做人设字段对齐；不必一次做满五种病例。

### 8.4 场景 · 这一局里 SP 扮演什么角色

场景回答：**谁在问、谁在答、桌上有什么、考什么。**

| 场景 | SP 角色 | 对行为的影响（不止长短） |
|------|---------|--------------------------|
| **知情同意** | 提问方 / 担心方 | ① 主动抛关切；学员主责 **讲解+回应** |
| **随访** | 被核查方 / 可能隐瞒方 | ② **披露深度是核心考点**；学员主责 **追问核查** |

同样「短」：知情里大爷短问「能退出吗？」vs 随访里建国短答「基本都吃了」—— **含义完全不同**（关切 vs 藏）。所以 **不能拿一套长度规则打天下**。

### 8.5 情绪 · 这一轮因学员态度而变

情绪主要改的是 **② 深度 + ③ 接话 + ④ 语气**；长短往往是伴随现象。

**李建国**

| 你说 | 行为变化（完整看） |
|------|-------------------|
| 「都吃了吧？」 | ① 不补信息；② 仍笼统；⑤ 短 |
| 「你怎么能忘！」 | ② **更瞒**；③ 「记不清」；④ 抵触；⑤ 更短 |
| 「不是责怪，哪一天？」 | ② **披露具体日期**；③ 「那我说实话」；⑤ 可略长 |

**张大妈**

| 你说 | 行为变化 |
|------|----------|
| （开场不信） | ① 连问钱/邻居；④ 半信半疑；⑤ 话多 |
| 「别听邻居的，赶紧签」 | ② 不愿听流程；③ 想结束；④ 抵触；⑤ 极短 |
| 「不着急，费用我讲清楚」 | ① 关切被接住；② 开始听流程；④ 信任升 |

**王阿姨：** 你太快 → ③ 请重复（话变多是 **理解策略**，不是话痨）。  
**张大爷：** 你讲清退出 → ① 关切落地，才愿意听后面风险。

系统：`patient_engine` 每轮更新 trust / stance / disclosure_depth，再约束「本轮允许说的事实」和 speak_style —— **管整套行为，不是只截字数**。

### 8.6 三因素叠加（架构表 + 流程）

| | 人设 | 场景 | 情绪 |
|---|------|------|------|
| **变不变** | 整场相对稳定 | 换局才变 | **每轮可变** |
| **主要管** | 关心什么、怕什么、理解习惯 | 问/答角色、桌上物品、考纲 | 这一轮藏多深、配不配合 |
| **典型字段** | persona、key_concerns | scene_key、session_script | emotion.stance、trust、depth |
| **举例** | 建国怕批评 | 随访要核查漏服 | 责备 → depth 下降 |

```text
开练：场景层定局 + 病例层定人（左右卡）
  ↓
每一轮学员发言
  ↓
运行时：读人设底色 → 套场景角色 → 更新情绪
  ↓
输出本轮 SP 行为（①～⑤）→ 回复 +（练习）心情/进度
```

**设计目的：** 练 **对人、对局、对当下状态** 的沟通，不是背固定脚本，也不是背「这个人要短句」。

## 九、架构落到 JSON · 新病人怎么装

写一个新 SP = 把 **三层架构** 填满：

| 架构 | 服务什么 | 在 JSON / 代码里 |
|------|----------|------------------|
| 场景层 | 开练左卡、评分对齐 | `scene_bindings` + rubric |
| 病例层 · 背景 | 开练右卡 | `persona`、`clinical_summary`、`session_script` |
| 病例层 · 开场 | 每次第一句不同 | `opening_pool` / `patient_greeting_seeds` |
| 病例层 · 事实 | 医学不漂 | `adherence_facts` / symptoms + `answer_pool` |
| 病例层 · 语气规则 | 责备/安抚怎么接 | `dialogue_hints` |
| 运行时 | ①～⑤ 整套行为 | `patient_engine`：trust、stance、depth、speak_style |

最小示例（张大妈 · 病例层）：

```json
{
  "persona": { "display_name": "张大妈", "lay_bio": "65岁独居，先问钱和跑几趟，半信半疑" },
  "clinical_summary": { "chief_complaint": "...", "social_notes": "..." },
  "session_script": { "visit_context": "...", "trainee_role_hint": "..." },
  "scene_design": {
    "opening_pool": [{ "id": "op_cost", "line": "要先问清楚，要钱不要？" }],
    "answer_pool": [{ "fact_id": "trial_duration_weeks", "fact_value": 12, "utterances": ["..."] }]
  },
  "dialogue_hints": { "if_rushed": "...", "if_reassuring": "..." },
  "scene_bindings": [{ "scene_key": "informed_consent", "enabled": true }]
}
```

## 十、验收 · 场景侧

- [ ] 能讲清 **三层架构**：场景 / 病例 / 运行时  
- [ ] 开练前 **左卡 + 右卡** 均可见  
- [ ] 知情三人：同评分表，**背景卡与关切可区分**  
- [ ] 李建国：笼统问/责备/具体问 → **披露深度与接话方式不同**（不只长短）  
- [ ] 答辩能说：三因素驱动 **说什么、说到多深、怎么接、语气、长短** 五件事  
- [ ] 同事实多种说法，**医学事实不漂**  
- [ ] 可走 **知情一人 + 随访李建国**，不依赖数字人/语音
