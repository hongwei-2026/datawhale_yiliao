# 示范话术 · 分场景测试版

> **怎么用：** 打开模拟对话 → 选人 → 对照下面「可复制剧本」逐句说 → 看左侧侧栏与检查点是否按预期变。  
> 不是背长稿；短句是 **示范节奏**，不是强制字数上限。  
> 关联：[01-场景设计](./01-场景设计.md) · [03-病人AI思考逻辑](./03-病人AI思考逻辑.md) · [09-评分体系](./09-评分体系与练习考核.md)

---

## 0. 测试前先认界面信号

| 你看的地方 | 用来验什么 |
|------------|------------|
| 开练页 · 受试者档案 | 场景 / 人设是否换人就换内容 |
| 开练页 · 练习任务 | 大类是否对（知情 vs 随访） |
| 练习中 · 左侧「受试者状态」 | 心情、信任、说到哪一步 |
| 练习中 · 左侧「沟通检查点」 | 任务覆盖（启发式，最终以结束清单为准） |
| 对话原文 | SP 是否含糊→松口、是否被责备后变短 |
| 结束 · 练习反馈 | 清单达标 / 红线 / 参考分 |

**建议顺序（约 30～40 分钟）：**

1. 李建国 · 情绪与披露（最容易一次验通）  
2. 王阿姨 · 知情关切与慢讲  
3. 张大爷 · 退出权 + 不夸大疗效  
4. 各做 1 次「红线反例」看抵触 / 结束否决  

> 对话太短（如 ≤2 轮）可能 **暂无参考分**，属设计，不是 bug。

## 一、李建国 · 第 4 周随访（追问 + 核查）

### 1.1 开练页应看到

| 项 | 期望 |
|----|------|
| 人 | 李建国 · 56 岁男 · 出租车司机 |
| 场景 | 第 4 周门诊随访 |
| 提示 | 平和追问；别一上来责备 |
| 任务大类 | 人文 · 用药与依从核查 · 随访安排与安全 · 红线 |

**病例锁死的真相（AI 不该一次倒完）：**

- 漏服：约第 10 / 19 / 24 天（女儿家、头晕后自行停等）  
- 第 18 天头晕约 20 分钟，**没打电话给中心**  
- 日记有补记；药盒可能多 3 片  
- 可能提过感冒药 / 自己加过原降压药  

---

### 1.2 可复制剧本 A · 验「笼统问不会一次倒真相」

| 轮 | 你说（可复制） | 期望现象 |
|----|----------------|----------|
| 1 | （听他先说） | 开场偏「没什么大问题 / 基本都吃了」一类 |
| 2 | `药都吃了吧？` | **仍含糊**（「基本都吃了」）；漏服检查点不宜一下全亮 |
| 3 | `最近有没有哪天忘记吃药？` | 仍可能含糊或只露一点 |
| 4 | `不是责怪您，我想了解真实情况。大概是哪一天？` | 心情趋缓；开始提「女儿家 / 某一天」 |
| 5 | `往前再想想，还有没有别的天？头晕以后有没有停过？` | 逐步到第 19、10 天等；「漏服」项更可能亮 |
| 6 | `那天头晕大概什么时候？有没有打电话给我们？` | 可提第 18 天、没联系中心 |
| 7 | `您桌上的药盒和日记本，我能不能一起对一下？` | 可能承认补记 / 剩药偏多 |

**侧栏对照：**

- 笼统问阶段：信任一般，「说到哪一步」偏浅  
- 安抚 + 具体日后：信任↑，话变具体  
- 检查点：先亮「平和 / 具体化」，再亮「漏服 / 头晕 / 药盒日记」

---

### 1.3 可复制剧本 B · 验「责备 → 抵触 → 更瞒」

| 轮 | 你说（可复制） | 期望现象 |
|----|----------------|----------|
| 1 | `药都按时吃了吧？` | 「基本都吃了」 |
| 2 | `你怎么能忘记吃药！这可是试验要求。` | 侧栏 **有点抵触**；话变更短 / 「记不太清」；信任↓ |
| 3 | `再这样就不能继续参加了，补助也没了。` | 更紧张；漏服 / 合并用药更避谈（红线风险） |
| 4 | `抱歉，刚才语气重了。不是责怪您，我们一起弄清楚就好。最近哪一天没吃上？` | 「那我说实话……」一类；开始松口 |

**要点：** 第 2～3 轮是在测情绪设计；测完用第 4 轮把信任拉回来，再继续核查。

---

### 1.4 随访 · 分项问法速查（可穿插）

| 你想覆盖的点 | 推荐问法 | 忌 |
|--------------|----------|-----|
| 漏服具体日 | 「哪一天忘了？往前推是周几？」 | 「都吃了吧？」就停 |
| 头晕 AE | 「有没有头晕、发飘？哪天？多久？有没有晕倒？」 | 自己下结论「一定是药的问题」 |
| 是否联系中心 | 「当时有没有打电话给研究中心？」 | — |
| 合并用药 | 「除了研究药，感冒药、以前降压药、保健品吃过吗？」 | 只问「有没有乱吃药」 |
| 药盒 | 「药盒还剩几片？我帮您对一下。」 | 指责「你是不是藏药」 |
| 日记 | 「本子上有没有后来补写的天数？」 | 「本子填满就行」 |
| 血压本 | 「家里血压本带来了吗？最近大概多少？」 | — |
| 下次安排 | 「下次大约什么时候来？不舒服打哪个电话？」 | 让他自己决定加药 / 停药 |

---

### 1.5 随访 · 红线反例（测完记得改口）

| 反例（不要当真用完就交卷） | 期望 |
|----------------------------|------|
| `你再漏服就开除出组。` | 恐吓 / 红线；抵触 |
| `头晕的话你自己先加回氨氯地平两片。` | 自行医嘱红线 |

**正解示范：**

- 「漏服了也不要自己随便补两倍；下次我们按方案告诉您怎么处理，不舒服先打电话给中心。」  
- 「加不加回原来的降压药，要听研究医生的，我先帮您记下来汇报。」

## 二、王阿姨 · II 期知情同意（讲解 + 回应）

### 2.1 开练页应看到

| 项 | 期望 |
|----|------|
| 人 | 王阿姨 · 72 岁女 · 听力略差 · 女儿常陪 |
| 场景 | S1 知情同意 · II 期口服降糖 |
| 关切 chips | 不参加是否影响常规治疗、脚麻视力、女儿陪同、交通抽血 |
| 提示 | **说慢点、确认听懂**；强调自愿退出不影响看病 |

---

### 2.2 可复制剧本 C · 验「慢讲 + 关切回应」

| 轮 | 你说（可复制） | 期望现象 |
|----|----------------|----------|
| 1 | （听她开场） | 常提：女儿在外等 / 说慢点 / 不参加还能看病吗 / 脚麻视力 |
| 2 | `王阿姨您先别急，我讲慢一点。听不清您随时打断我。` | 她更愿意听；人文类检查点易亮 |
| 3 | `不参加完全可以，也不影响您平时在这边看糖尿病。` | 她确认「不得罪你们」一类；关切项推进 |
| 4 | `这个药还在研究，能不能降糖、降多少，我们没法打包票。我们会定期查血糖，也会问您有没有不舒服。` | 不夸大；她可能追问副作用找谁 |
| 5 | `您担心的脚麻、看东西发花，我们会记在病情里，入组后也会监测；但现在不能保证一定好或一定坏。` | 正面回应症状关切 |
| 6 | `大概要来医院几次抽血，我们会说清楚时间和有没有交通补贴；您女儿也可以一起听说明。` | 流程 / 负担类 |

**若你说太快：**

- 你：`（一口气讲完目的风险获益流程补偿）`  
- 期望：她说「太快了，再说一遍」一类  

**若你责备血糖：**

- 你：`都是您血糖没控制好才要来做试验。`  
- 期望：更不敢、更紧张  

---

### 2.3 知情 · 分项话术速查

| 大类 | 你可以这么说 |
|------|----------------|
| 人文 | 「有问题随时打断我；我讲完一段您告诉我听懂没有。」 |
| 试验目的 | 「主要是看看这个药对血糖能不能帮忙，还要看安不安全。」 |
| 随机/对照 | 「可能分到试验药或对照，具体以知情同意书为准，我们不会故意瞒您分组规则。」 |
| 风险 | 「可能会有拉肚子、心慌等不适，严重的少见，但出现了要告诉我们。」 |
| 获益不确定 | 「可能有帮助，也可能感觉不到；不能保证一定有效。」 |
| 退出权 | 「随时可以说不参加或中途退出，不影响平时看病。」 |
| 流程 | 「大概要来几次、抽血、带药；我们按访视表说清楚。」 |

---

### 2.4 知情 · 红线反例

| 反例 | 期望 |
|------|------|
| `不签的话以后在这看病就不方便了。` | 强迫 / 利诱感；抵触 |
| `这个新药肯定能把您血糖治好。` | 夸大疗效红线 |
| `副作用那些您先不用看，问题不大。` | 隐瞒风险倾向 |

## 三、张大爷 · 知情同意（退出 + 疗效反复确认）

### 3.1 人设要点（开练档案）

- 68 岁左右退休男，爱把「能不能退出」「是不是一定有效」**问两遍**  
- 不无故隐瞒，但听副作用会紧张  
- 你要：**讲清楚 + 耐心复述关键权利**，别嫌他烦  

### 3.2 可复制剧本 D · 验「关切要答、可重复」

| 轮 | 你说（可复制） | 期望现象 |
|----|----------------|----------|
| 1 | `张大爷您好，今天跟您说明这个试验，有疑问随时问我。` | 建立可问框架 |
| 2 | （他若问退出）`可以中途不参加，随时退出，不影响平时看病。` | 他可能再问一遍 → 你再答一遍也正常 |
| 3 | （他若问疗效）`还在研究阶段，对您个人能不能降糖，我们没法保证。` | 不包治；他可能追问「那我图什么」 |
| 4 | `图的是把情况监测清楚，也给研究积累证据；对您个人有没有好处，要诚实说：不确定。` | 关切回应 |
| 5 | `大概十二周、按访视来测血糖；平时多数药能否继续，我们按清单和您核对。` | 流程可分轮讲，别一轮塞爆 |

## 四、专练某一类（短测脚本）

不必每次完整通关。例如：

### 只练「关切回应」（知情）

1. 选王阿姨或张大爷  
2. 只聊 4～6 轮：专等她/他问退出、疗效、副作用，你答  
3. 结束 → 看「回应受试者关切」大类是否相对更好  

### 只练「漏服核查」（随访）

1. 选李建国  
2. 专问日期，不责备  
3. 结束 → 看「用药与依从核查」  

### 只练「情绪」

1. 建国：先责备 1 句 → 看侧栏抵触  
2. 再安抚 + 具体日 → 看信任回升  
3. **不必交卷**；验证完可结束或继续正规核查

## 五、现象对照表（测的时候对号入座）

| 你看到的 | 多半意味着 | 不一定是 bug |
|----------|------------|--------------|
| SP 反复问同一句 | 信任不够 / 你答太短或回避 | 知情大爷人设就会重复确认 |
| 检查点变「可能达标」 | 关键词启发式命中 | 最终以结束清单为准 |
| SP 突然很短、防备 | 可能被责备 / 威胁 | 情绪设计在工作 |
| 笼统问永远「基本都吃了」 | 披露深度未打开 | 符合随访藏话设计 |
| 同病例第二次说法变了 | 开场多样性 | 事实应仍一致（漏服天数等） |
| 「样本不足，暂无参考分」 | 轮次/字数不够 | 防刷分设计 |
| 心情变了但检查点不动 | 两套信号不同源 | 先看原文是否真问到点 |
| 已松口但漏服项不亮 | 你可能没问「哪一天」等关键词 | 再补一句具体日 |

## 六、10 分钟快速验收清单（建议你现在就勾）

**李建国**

- [ ] 开练档案能看出「怕批评、先含糊」  
- [ ] `药都吃了吧？` → 仍含糊  
- [ ] 责备 → 侧栏抵触 / 信任下降  
- [ ] 安抚 +「哪一天」→ 开始说女儿家 / 具体天  
- [ ] 追问头晕 → 能问到「有没有联系中心」  
- [ ] 不出现自己编造的「住院 / 晕倒」等库外大事件  

**王阿姨**

- [ ] 开场有听力 / 女儿 / 退出或脚麻关切之一  
- [ ] 你说慢 + 退出不影响看病 → 她更配合  
- [ ] 你夸大疗效 → 她不安或系统红线风险  
- [ ] 讲太快 → 她要求再说一遍（若触发）  

**张大爷**

- [ ] 退出权说清后他仍可能再问 → 你再答一次合理  
- [ ] 「一定有效」类话术应避免；他听副作用会紧张

## 七、建议练习顺序（完整一晚）

1. **建国剧本 B**（情绪）3～4 轮 → 截侧栏  
2. **建国剧本 A**（披露）6～8 轮 → 看检查点  
3. **王阿姨剧本 C** → 看关切与人文  
4. **张大爷剧本 D** → 看重复确认  
5. 各做 1 次红线反例（点到即止）→ 看结束反馈  
6. 回看 [03](./03-病人AI思考逻辑.md) 四幕，勾「是否出现」
