## 一、先讲故事：李建国这一场随访

### 1.1 他是谁（开练右卡就该看到）

56 岁出租车司机，高血压 III 期试验 **入组第 4 周**来随访。  
嘴上客气：「基本都吃了。」  
病例里锁着的真相：**漏服 3 天、第 18 天头晕后自行停药、偷加原降压药、日记补记、药盒多 3 片**。  
他怕什么：**做错被批评、不能继续参加、补助没了**——所以 **不会一进门全说**。

### 1.2 四幕对话

**第一幕 · 进门**  
建国：「大夫我来了……药吧，基本都按时吃的。」  
→ 太笼统。学员若到此为止，**漏服核查还没问到**。

**第二幕 · 问太宽**  
学员：「都吃了吧？」  
建国：「嗯，基本都吃了。」  
→ 仍含糊。系统不会把「漏服」标成已覆盖——要 **具体哪一天**。

**第三幕 · 责备**  
学员：「你怎么能忘记吃！」  
建国：「我也不是故意的……可能记错了。」（更短、更防备）  
→ 界面可显示「有点抵触」。他 **更不敢说** 三次漏服和自行加药。

**第四幕 · 安抚 + 具体问**  
学员：「不是责怪，想了解真实情况。哪一天没吃？」  
建国：「去女儿家那天……就忘了。」  
→ 信任上来，开始松口；再追问才带出第 10、19 天和药盒、日记。  
→ 这时「漏服核查」才可能亮进度。

### 1.3 若换成张大爷（知情）会怎样

同一套「思考逻辑」，**场景不同，想的事不同**：

- 张大爷主要 **提问**：退出？有效？  
- 李建国主要 **答问且先藏**：没事 → 含糊 → 被问具体才说  

病人 AI 不是一套固定话术，是 **按人、按局、按这一轮态度** 决定「想说什么、敢说多深」。

## 二、从故事里发现问题

| # | 故事里发生了什么 | 暴露的问题 |
|---|------------------|------------|
| **Q1** | 「都吃了吧」永远得到「基本都吃了」 | 笼统问不能一次倒出全部真相——要有 **披露深度** |
| **Q2** | 责备后更防备，安抚后才说女儿家那天 | 态度会改 **敢不敢说、怎么接话**——要有 **情绪状态** |
| **Q3** | 病例里有 3 次漏服，但他不能主动背出来 | 真相在 JSON；AI **不能编、也不能一次倾倒** |
| **Q4** | 知情大爷和随访建国「想」的不一样 | 思考规则要挂 **人设 + 场景**，不能全国一套 prompt |

**一句话：**  
病人 AI 要解决的是——**像真人一样藏与松口，又绝不脱离病例事实。**

## 三、设计总览：病人 AI「怎么想」

### 3.1 核心公式（对外可背）

```text
人设底色（怕什么、藏多深）
  × 场景角色（知情爱问 / 随访先藏）
  × 本轮情绪（信任、stance）
        ↓
决定这一轮五件事：
  ① 说/问什么话题
  ② 说到多深（含糊→细节）
  ③ 怎么接学员的话
  ④ 语气与配合度
  ⑤ 说多长（只是其中一项）
```

与 [01 第八节](./01-场景设计.md) 运行时一致；本文讲 **思考链路怎么落成规则**。

### 3.2 思考流水线（每一轮）

<img src="assets/prd2-patient-thinking-flow.png" alt="病人 AI 思考四步流水线" width="100%" />

```text
学员说一句
    │
    ▼
① 听语气     → 责备？安抚？笼统？具体日期？
    │
    ▼
② 改心情     → 更新 trust / stance（抵触、放松…）
    │
    ▼
③ 定披露     → 本轮允许提到哪些事实、多细
    │
    ▼
④ 说出口     → 在允许范围内说人话（可抽说法变体）
```

```text
┌────────────┐   ┌────────────┐   ┌────────────┐
│ 病例事实库  │ → │ 思考/披露  │ → │ 口语生成   │
│ 漏服3次…   │   │ 引擎       │   │ LLM        │
└────────────┘   └────────────┘   └────────────┘
     锁死              规则算              说人话
```

**原则：规则管「能不能说、说到哪」；模型管「怎么说得像人」。**

## 四、具体怎么设计（按思考四步讲）

### 4.1 听语气 —— 学员这句话触发了什么

病例里的 `dialogue_hints` + 通用规则，例如：

| 学员语气 | 触发 | 建国倾向 |
|----------|------|----------|
| 「都吃了吧」 | 笼统问 | 继续含糊 |
| 「怎么能不按要求」 | 责备 | 防备、少说 |
| 「不是责怪，了解真实情况」 | 安抚 | 愿意往下说 |
| 「哪一天、往前推」 | 具体化 | 逐步说出日期 |

**设计目的：** 没有「听语气」，就没有第三幕到第四幕的转变。

### 4.2 改心情 —— 状态怎么变

维护每轮状态（已有 `patient_engine`）：

| 字段 | 含义 | 故事里 |
|------|------|--------|
| `trust` | 信任 0～100 | 责备降、安抚升 |
| `stance` | 配合/保留/抵触/想走/放松 | HUD「有点抵触」 |
| `disclosure_depth` | 愿意说到哪一档 | 0 几乎不实说 → 3 可说细节 |

人设影响初始值：建国 `concealment` 中等 → 开局就偏保留，不会一上来 depth=3。

### 4.3 定披露 —— 本轮「允许说的事实清单」

按 depth 从病例裁剪，例如漏服：

| depth | 允许说 |
|-------|--------|
| 低 | 「基本都吃了」「好像有几天忘了」 |
| 中 | 可暗示某次外出、头晕后停过 |
| 高 | 可说清第 10/19/24 天等（仍不替医生下结论） |

**禁止：**

- 编造晕倒、住院等未登记事件  
- 一次倒出全部隐瞒（除非深度已够且被平和追问）  
- 脱离 `adherence_facts` 改次数  

### 4.4 说出口 —— 口语怎么生成

1. 带上「本轮心情 + 说话方式 + 允许事实」  
2. 可选：从答案变体池抽一种说法（次数仍是 3）  
3. LLM 生成口语；后处理去掉 Markdown  

说话方式示例（`SPEAK_STYLE`）：

| stance | 给模型的倾向 |
|--------|----------------|
| 愿意配合 | 语气自然，可多说一两句 |
| 有所保留 | 短句、含糊，不主动展开 |
| 有点抵触 | 短句，略委屈或反问，不骂人 |
| 不太想聊 | 极短 |
| 放松了一些 | 可说「那我说实话」 |

→ 长短是 **思考结果的外显**，不是单独目标。

## 五、和知情场景怎么共用这套逻辑

| | 李建国（随访） | 张大爷（知情） |
|---|---------------|----------------|
| 场景角色 | 被核查，先藏 | 提问方，反复确认 |
| 思考重点 | 披露深度、防责备 | 关切是否被回应 |
| 触发松口 | 安抚 + 具体日期 | 讲清退出/不夸大疗效 |
| 学员忌 | 一轮三考点、责备 | 不回应关切、催签 |

**同一引擎，不同病例 JSON（人设、hints、事实）** —— 不是两套 AI。

## 六、和界面、评分怎么咬合

| 学员看到的 | 背后思考逻辑 |
|------------|--------------|
| 「受试者：有点抵触」 | stance 变了（练习可见；考核应隐藏） |
| 漏服进度不亮 | 披露未到、或问法太笼统 |
| 漏服进度可能亮 | 具体问到且允许披露 |
| 结束报告里的证据 | 最终评分看整段对话，不单看过程亮灯 |

## 七、对外 2 分钟讲稿

1. **故事：** 建国先说没事 → 笼统问仍含糊 → 责备更瞒 → 安抚后说女儿家那天。  
2. **问题：** 要藏、要松口、要不编事实、要分人分局。  
3. **设计：** 每轮四步——听语气 → 改心情 → 定披露 → 说出口。  
4. **收束：** 规则管边界，模型管口语；和场景设计的「五维行为」一致。

## 八、验收自测（李建国三句）

1. 「药都吃了吧？」→ 仍含糊，漏服不宜算覆盖  
2. 「你怎么能忘记！」→ 抵触，更防备  
3. 「不是责怪，哪天没吃？」→ 放松，开始提具体漏服  

三步都对 → 思考链路通。
