# 数据库 DDL（全项目）

- [`schema.sql`](./schema.sql) — PostgreSQL 14+ 全库建表  
  - **M0** 场景 / 用户 / 导入日志  
  - **M1** 标准注册、条款、术语、评分对照表  
  - **M2** 病例事实包（疾病、症状、风险、人设…）  
  - **M3** 训练会话、消息、评分结果、反馈报告  
  - **M4** AI 模型、Prompt 版本、生成日志、事实校验  
  - **M5** 导读与白话内容（可选）

设计说明：[`数据库设计文档.md`](../数据库设计文档.md)  
业务依据：[`标准设计文档.md`](../标准设计文档.md)、[`病例设计文档.md`](../病例设计文档.md)

一期可继续用 `web/data/*.json`；上线时执行本 schema 并导入 JSON。
